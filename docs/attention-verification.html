Orca · Attention

A few small moves.
A calmer inbox.

Attention gives senders a home. Inside a message or the inbox, you can also move just one conversation.

Open Attention → · The mailbox uses sample messages; changes never touch your real mail.

1. Move one conversation

Open Kickoff notes from Maya. Choose This conversation → Quiet. It should leave Inbox and appear in Quiet. Maya’s Thursday review should stay in Inbox.

2. Choose a home for a sender

In Attention, add maya@studio.example to Quiet for the work account. Thursday review should follow that sender choice. Maya’s dinner message in the personal account should stay where it was.

3. Make an exception

Move Kickoff notes to Inbox for this conversation. The sender can stay Quiet while that conversation stays in Inbox. Choose Use sender choice to make the conversation follow the sender again.

4. Change your mind

Change a sender’s destination, then use Undo. Reload the page to check that the restored choice stays saved. If another change has happened since, Undo should explain the conflict instead of replacing that newer choice.

5. Try it your way

Search for a sender, switch accounts, and try both themes. The main question: can you tell where a message will go and how much each choice affects?

Attention

Inside a message

Inbox and Quiet describe where mail appears in Orca. Notification delivery is a separate capability and is not available in this implementation.
Run this sample mailbox locally
bun install --frozen-lockfile
bun run --cwd apps/web build
ATTENTION_REPO="$PWD" ATTENTION_PREVIEW_PORT=51439 bun scripts/attention-workflow-preview.ts

The script creates a fresh disposable database and a fixture session. It does not use your production mailbox. For a pagination fixture, also set ATTENTION_PREVIEW_EXTRA_MESSAGES=120.
