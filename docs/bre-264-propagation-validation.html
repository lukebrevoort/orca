Deterministic propagation, end to end.

Important automated mail becomes a concise local event after normalization and Human Signal classification. The path is account-scoped, retry-safe, provider-read-only, and works without OpenAI or any other model provider.

Evaluate

Persist
SQLite creates, no-ops, or updates by fingerprint.

Privacy and telemetry

Logs contain account/provider source IDs, trigger, rule/agent versions, kind, reason codes, destination, and outcome. Failures log only an error class name. Subjects, bodies, headers, sender addresses, source URLs, exception messages, OAuth tokens, and secrets are excluded.

Lifecycle semantics

An identical retry is a strict no-op. A changed assessment for the same provider message updates the bounded projection and increments revision while preserving disposition. A new provider message keeps its own immutable source event; invalidation/retraction remains explicit.
