Production chunks still load eagerly. This change reduces the largest chunk and separates cacheable dependency families; it does not claim a large reduction in initial transfer. Total JavaScript is about 927.67 kB (262.82 kB gzip), versus 931.96 kB (262.46 kB gzip) before.

Why these boundaries

React is a stable runtime family. Mail contracts group shared schemas and Zod so schema initialization stays together. Organization Views is an existing feature module; Rollup includes its dependency closure, including guidance and top-layer contexts, to prevent back-imports into the application entry. No application, desktop shell, or style source edits were required.

The development feedback widget now loads through a guarded dynamic import. Its JavaScript and stylesheet are removed from production. CSS decreases from 378.73 to 367.34 kB total. Existing Orca CSS overrides for development feedback remain.

Measured contributors

The report identifies React DOM as the largest framework contributor, Zod and shared schemas as the largest contract contributors, and App, Organization Views, desktop shell, and compose as the largest application contributors. Per-module rendered lengths are measured before final minification; only the chunk totals above represent minified bytes.
