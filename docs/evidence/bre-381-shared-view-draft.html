Authority and cursor invariants

  • Explicit inaccessible Accounts and referenced Lane, Facet, Context, relationship, or Workflow resources are rejected—never silently intersected.
  • Every page rechecks live query capability, Actor, Workspace, Account scope, and required resource families.
  • Cursor v2 binds definition digest, authorized scope digest, cumulative shown count, and the complete (receivedAt, accountId, threadId) keyset.
  • Any cursor field tamper, scope expansion, View revision change, or permission revocation fails closed.

Honest interaction state

  • Draft edits synchronously stale the prior generation, abort its request, and disable Save.
  • Only a matching generation and definition digest can re-enable Save.
  • Pagination reports “N shown” until exact exhaustion.
  • match_all is distinct from a filtered exact zero; zero requires a second digest-bound confirmation.
  • Commit failures retain the same retry key; success opens the real persisted View.
