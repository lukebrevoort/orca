Incremental checkpoint proof

  • Initial page queries from epoch and stores its page token plus a fixed import window.
  • Resumed pages retain that exact window, so the import is resumable.
  • Completion stores the import start as last_synced_at.
  • The next refresh queries from that saved timestamp, not epoch.
