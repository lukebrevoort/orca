## 4. Behavior

Any future reply-review capability must disclose account/sent coverage and its real eligibility before exposure; read alone never proves a reply. Keep unsupported features honestly unavailable.

## 5. State machine

Draft/message opening → ready/error/canceled without installing stale content. Offline snapshots are labeled if genuinely available; do not invent cache support. Owner/session changes clear inaccessible sections and invalidate delayed opens. Future dismissal/snooze states require their own verified contract.
