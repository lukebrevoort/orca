Typography and iconography

Native system fonts scale with the user’s settings. Serif emphasis may distinguish the Orca heading; reading body stays simple and generous. SF Symbols provide consistent outlines and native accessibility; text labels accompany consequential actions. Sender glyphs supplement sender names.

Composition and density

Inbox rows prioritize sender, subject, then preview. Reader headers compress secondary metadata; complete recipients remain discoverable. Composer puts words above optional formatting. Use surface groups and fine separators, not stacked decorative cards.

Shape, elevation and imagery

Native sheets establish hierarchy. Small corner radii soften controls. Shadows are reserved for overlays. No decorative stock images, gradients, or imagery that competes with the mail.

Motion and feedback

Native transitions, no custom loading theatrics. Respect Reduce Motion. Success text persists long enough to understand; draft saved status is stable. Error and warning colors always accompany a label.

Page annotations

Authentication uses a focused form. Lists use repeated aligned rows. Detail uses a reading column. Writing uses a full-height editor. Settings uses native groups. Recovery appears next to the affected action. Desktop-only page types are out of scope.

Reference contrast checks

Calculated sRGB contrast: light ink on paper 15.22:1; light secondary on white 6.15:1; light accent on white 5.26:1; dark ink on surface 16.15:1; dark secondary 7.62:1; dark accent 9.75:1. These reference pairs exceed 4.5:1; native control-state validation remains a separate check.

Control states

Default, focus, pressed, selected and disabled labels must remain visible in both themes. Pointer hover uses the surfaced treatment on devices that support it. The implementation review will inspect simulator screenshots and native controls, not infer success from token values alone.
