Product briefCore flows

Before the phone test

  1. Deploy the reviewed API and web changes together, including the mobile-auth browser handoff and database migrations. The iPhone server setting must point at your HTTPS Orca origin that serves /v1.
  2. Open apps/ios/Orca.xcodeproj in Xcode. Select your Apple development team and an App ID you own. The bundle ID and APNS_BUNDLE_ID must match.
  3. Enable Push Notifications for that App ID and provision the signed build. Configure server-side APNS_TEAM_ID, APNS_KEY_ID, APNS_BUNDLE_ID, and APNS_PRIVATE_KEY. Keep the signing key out of the app and repository.
  4. Keep the existing Gmail push/watch setup active so new mail reaches Orca promptly. Apple delivery begins after Orca ingests an eligible message.
  5. Connect your phone and install through Xcode, or distribute a signed release through your Apple distribution workflow.

Simulator notification injection verifies routing and presentation. It does not prove real APNs delivery, signing, Gmail ingestion latency, or background behavior on your phone.
