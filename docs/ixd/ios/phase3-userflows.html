Connect and return

flowchart TD
 A[Enter server] --> B[Create PKCE request]
 B --> C[System browser login]
 C --> D[Explicit named-account consent]
 D --> E[Single-use code callback]
 E --> F[Exchange with verifier]
 F --> G[Store credential in Keychain]
 G --> H[Inbox]
 C -. Cancel .-> A
 F -. Invalid or expired .-> A

Validate HTTPS origin before networking. Browser consent names the account. Validate callback scheme, host and state before exchanging. A canceled attempt returns to the connect screen; it never signs in as a different account.

Read and reply

flowchart TD
 A[Inbox or notification] --> B[Fetch scoped conversation]
 B --> C[Read]
 C --> D[Reply or reply all]
 D --> E[Persist local draft]
 E --> F[Save server revision]
 F --> G[Confirm send]
 G --> H[Persist idempotency key]
 H --> I[Send]
 I --> J[Confirmed delivery]
 I -. Timeout .-> K[Check delivery]
 F -. Conflict .-> L[Preserve local copy]

The account and reply context stay fixed once writing begins. Reply-all deduplicates addresses and excludes the sending identity. Mark-read changes are local Orca state; no unsupported provider archive/star promise is shown.

Recover interrupted writing

flowchart TD
 A[Edit] --> B[Atomic local save]
 B --> C{Online?}
 C -->|Yes| D[Revisioned server save]
 C -->|No| E[Saved on this phone]
 E --> F[Reconnect or reopen]
 F --> D
 D -. Revision conflict .-> G[Keep local words and show conflict]
 A -. Dismiss .-> H[Drafts]
 H --> A

Local content is saved before network work, scoped to server and signed-in identity. Delivery states sending/sent/ambiguous are not editable drafts. A timeout must not generate a new send command. Confirmed sent items leave the editable list.

Receive useful notifications

flowchart TD
 A[Enable notifications] --> B[System permission]
 B --> C[Register APNs token]
 C --> D[Authenticated device registration]
 D --> E[New eligible mail]
 E --> F[Durable deduplicated outbox]
 F --> G[APNs]
 G --> H[Tap]
 H --> I{Signed in?}
 I -->|Yes| J[Scoped conversation]
 I -->|No| K[Reconnect then resolve]
 B -. Denied .-> L[Explain settings path]

Default eligibility is Inbox; individual Spaces can be selected independently. Human Signal does not gate alerts. Device registration establishes a watermark; backfill does not alert. Payloads contain opaque routing IDs and generic text. Server configuration, system permission and device registration are separate statuses. Turning notifications off and signing out stop future delivery.

Shared recovery behavior

Every network operation has loading and retry feedback. Cached data is labeled. Authentication failure returns to connection while preserving owner-scoped draft recovery. Network failure never falls back silently to demonstration data. Provider consent is requested only when the user chooses the relevant writing capability.
