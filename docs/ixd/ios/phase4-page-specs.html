P01 · Connect Orca

Overview and entry

Signed-out launch or expired session. Configure HTTPS origin, sign in through browser, consent to the named account; return safely on cancellation.

Layout and components

System safe areas and navigation above scrollable content; relevant primary action remains reachable. Reuse account context, status banner, labeled buttons and native sheets. Reading and writing content gets the largest region.

Interactions and exit

Every action is labeled; icon-only controls expose an accessibility label. Back and dismiss retain the upstream context. In-flight destructive or delivery commands cannot be repeated by rapid taps. Changes are confirmed before leaving only when a local save failed or the user requested discard.

States and feedback

Include loading, populated, empty, offline, failure and unauthorized variants where applicable. Inline errors explain the next action. Native disabled controls retain readable labels. Selection uses the surface, border and ink tokens together.

Data and scope

All mail data belongs to the selected server, authenticated identity and account. Fetches canceled by account changes cannot repaint another account. A notification route validates account ownership through the server.

Adaptation and accessibility

Support Dynamic Type and VoiceOver. Do not depend on color or swipe gestures alone. Layout scrolls at accessibility sizes. Native keyboard avoidance protects the writing cursor and send action.

Motion and micro-interactions

Use system navigation and sheet transitions; respect Reduce Motion. Save and send feedback is textual, never a transient animation alone. No decorative motion while reading.

Verification

Exercise this page in light and dark mode, with large text, keyboard focus, populated and error states. Screenshots demonstrate appearance; automated integration tests demonstrate persistence and isolation.
