Human Inbox, Tideline, and safe corrections

Validation notes for the server-backed classification surfaces. The screenshots below were captured from the running Vite SPA at http://localhost:5173/dev/inbox, with the local API running at http://localhost:3000.

Surface contract

ViewBehavior
Human InboxLikely-human messages, with unread/pin context.
TidelineAutomated or bulk signal, kept out of the human stream.
ReviewUncertain and unclassified messages for later review.
All mailEvery classified message, with provider/account scope preserved.

Correction flow

  • Choose message, sender address, or sender domain scope.
  • Save likely-human, automated/bulk, or uncertain.
  • Reset to the automatic Orca estimate.
  • Provider mail is never mutated by a correction.
  • Thread opens remain account-scoped.
