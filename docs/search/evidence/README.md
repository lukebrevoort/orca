# Synthetic resource evidence

- `final-read.json`: frozen-core read/count measurements on a 20k tiny-message fixture
- `capture-and-write.json`: earlier capture and actual bounded child/write measurements; its read phase is superseded
- `cost-model.json`: arithmetic from synthetic benchmark coefficients and explicit hypothetical workload volumes

Local filesystem paths are redacted. Measured values and source hashes are retained. These are ordinary local implementation measurements, not production capacity, large-body stress, or completed security validation. Compare recorded hashes before attributing results to a later source head. The [cost report](../queued-search-costs.md) explains the assumptions and exclusions.
