BRE-135 · Repeatable review guide

The full M2
reading journey.

Use the demo inbox at /dev/inbox and the reading settings at /settings/reading. Complete every card with mouse and keyboard, then repeat the visual checks in light/dark and narrow/wide viewports.

Reader

Find and read

Inbox → conversation → return without losing place.

  1. Open a thread and confirm the subject receives focus.
  2. Check chronological messages, unread/newest labels, details disclosure, quoted-history disclosure, and attachments.
  3. Use jump-to-newest/top on a long thread.
  4. Press Escape or Back to inbox; confirm focus returns to the originating row.
Attention

Change and explain

Every sender treatment remains legible, understandable, and reversible.

  1. Open Tune for a sender and inspect the explanation.
  2. Move the sender to Notify, Focus, Quiet, and Hidden.
  3. Confirm the destination view immediately and recover the sender from each view.
  4. Restore Keep in inbox and confirm the selected label remains readable in both themes.
Reminder

Defer and return

A reminder is editable and never removes the thread permanently.

  1. Choose Remind me and adjust hours/days using keyboard controls.
  2. Confirm the notification checkbox follows the reading preference default.
  3. Save, open Later, and verify the return time.
  4. Complete and cancel reminders; confirm both actions remove the thread from Later without deleting mail.
Collections

Organize safely

Collections and pins are reversible views over existing mail.

  1. Create, rename, recolor, and reorder a collection.
  2. Add/remove a thread and verify membership counts.
  3. Pin a view, sender, and thread; reorder and remove each.
  4. Confirm no action changes or deletes the Gmail source.
Migration

Bring labels forward

Gmail remains read-only throughout migration.

  1. Open Gmail labels settings and wait for the ready state.
  2. Select labels by keyboard; confirm count and selected labels in both themes.
  3. Import and verify one collection per selected label.
  4. Confirm the page explicitly says labels are never renamed, removed, or edited.
Preferences

Read your way

Device defaults are honored until explicitly overridden.

  1. Start with system defaults; change OS light/dark and reduced motion.
  2. Override theme, standard/large text, calm/compact density, and system/reduced/full motion.
  3. Reload after each choice and confirm it persists.
  4. Use system defaults and verify all preferences reset together.
