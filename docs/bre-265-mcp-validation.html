Orca mail,
quietly readable.

A narrow Streamable HTTP MCP surface for inspecting normalized mail and propagated events. Every operation is account-scoped, read-only, bounded, schema-defined, and explicit about untrusted email content.

Implementation verified

The four-tool surface

search_mail

Find mail by text, account, sender, time, attention, Human Inbox/Tideline class, and bound cursor.

metadata scope · max 50
get_thread

Read one account-attributed thread with plain-text excerpts and per-message Human Signal explanations.

content scope · no HTML or attachments
list_agent_events

Review concise propagated events with lifecycle, provenance, explanations, and stable source references.

event scope · no owner or dedupe internals
get_connection_status

Check authorized account identity, sync state, and read readiness without provider grants or credentials.

status scope · read-only capability
