On your iPhone after deployment

Use fresh messages after each setting reaches its synced status. Use an existing Space whose matching rules you know. These checkboxes are temporary notes for this page.

Choices are per device and identity. They must sync to the server before affecting background delivery. Alerts already submitted to Apple or displayed cannot be recalled by changing a selection. Existing queued payloads retain their old generic text; newly queued messages use the richer preview.

Preview text is included in the APNs alert payload. Raw HTML, recipients and attachments are not included. Long text is shortened, and missing fields receive readable fallbacks.
