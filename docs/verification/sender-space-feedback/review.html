Senders, saved views & selection tools

BRE-406 · BRE-408 · BRE-409 · BRE-410 · BRE-411

What changed

  • Senders is a persistent Tools destination. Customize tools manages Later and collections; Settings and mobile use the same workflow.
  • Use these senders opens a compact save dialog. Name and exact scope stay visible, extras live in Tune, and matching messages expand on demand.
  • Saved views use readable mail rows and a keyboard/touch correction menu.
  • Selection actions flow below sync notices. Move to space has separated choices and a spaced footer.

Manual checks

  1. Open Senders from Tools; switch account and search. Open Customize tools from Settings, rename/hide/restore Later or a collection.
  2. Select one or more messages. Open Use these senders, inspect account and addresses, edit the name, open Tune, then Escape twice and discard. Selection and focus return.
  3. Save a sender view. Inspect sender, account, date, and subject; open the row action menu, then Correct senders. Cancel or save through the existing preview flow.
  4. With a long sync warning, inspect zero/one/many selections at 1440px and 1024px, expand Sender preferences, and scroll. Warning and toolbar never overlap.
  5. Open Move to space. Choose a destination, inspect the selected state, Cancel, then reopen and move the selected conversations.

Repeat in Light and Orca Black. Scratch mail only; provider requests are replaced by a no-op.
