Fast manual check

  1. Run bun run dev and open compose.
  2. Type a subject and body. Confirm the status moves through Saving to Saved to Orca (and Gmail when compose access exists).
  3. Refresh. Confirm the exact subject and body return.
  4. Set the browser offline, edit again, and confirm the copy says it is safe on this device and will retry.
  5. In two tabs, edit the same revision. Confirm the stale tab offers “Use newer version” or “Keep mine as a new draft.”
  6. Discard. Confirm the prompt names Orca and Gmail; a failed Gmail cleanup must keep the Orca draft available for retry.
