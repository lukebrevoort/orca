Fast manual check

  1. Run bun install, then bun run dev. Open /dev/inbox for the UI preview and /settings/integrations/gmail for the real account flow.
  2. In Settings, confirm a read-only account sees the minimum gmail.compose upgrade explanation. Cancel or deny the upgrade and confirm the inbox remains readable.
  3. Open Compose, enter a recipient, subject, body, Cc, and Bcc. Confirm the saved status becomes explicit, then reload and confirm the text recovers. Add an image and a document, remove one, and confirm binary files are never restored from local storage.
  4. Open Zen mode and return with Escape or the Return to compose control. Confirm focus and content remain in the writing journey.
  5. With compose access granted, send once. Double-click Send or retry a response-lost request in the safety tests. Confirm the message is not delivered twice, the conversation refreshes, and reopening Compose starts blank.
  6. Open a thread and exercise Reply, Reply all, and Forward. Confirm external recipients are selected correctly, Bcc is not exposed to other recipients, and the thread remains intact after reconciliation.
  7. Discard a draft, simulate offline mode, and simulate a stale revision or provider cleanup failure. Confirm the copy says what is safe, what is retryable, and what action is blocked.

Safety matrix

Delivery reservation

The API reserves a draft with a unique idempotency key before calling Gmail. A second command returns the durable result instead of sending again.

Ambiguous provider response

Timeouts and unknown upstream failures become an explicit ambiguous state. Retrying inspects the durable draft and reuses the same key.

Recipient privacy

To, Cc, and Bcc remain distinct through shared schemas and MIME encoding. Logs and public errors use bounded messages rather than provider payloads.

Account isolation

Draft reads, writes, deletes, and sends are scoped to the connected account behind the authenticated user session.

Provider recovery

Draft mirroring is revision-aware; a missing Gmail draft is recreated, and failed cleanup keeps the Orca copy available for retry.

Thread correctness

Replies hydrate missing Message-ID and References headers. Forwards intentionally start a new provider thread.

Responsive and accessible states

  • At wide and narrow widths, verify the compose panel, Zen mode, recipient fields, attachment chips, conflict choice, send, discard, and permission dialog remain usable without horizontal scrolling.
  • Repeat selected, hover, focus, disabled, saving, saved, error, and sending states in both themes. Labels must remain readable; selected controls use the established surface-hover treatment.
  • With reduced motion enabled, confirm the writing flow still works without transition-dependent focus loss. Escape closes Zen mode and restores the previous writing context.
