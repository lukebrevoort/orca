Failure isolation

Mail survives

The sync result—not propagation—is authoritative for ingestion. The Gmail integration suite injects storage and evaluator failures, verifies the source message remains stored, and asserts body and exception secret markers never enter structured telemetry.

Manual local + external-agent path

  1. Install dependencies and migrate a disposable development database. Do not paste real tokens into terminal output or screenshots.
  2. Enable deterministic propagation, load the M6 fixture inbox, and start API + web. No OpenAI environment variable is required.
  3. Open the base timeline. Confirm the release event appears, its explanation is plain, and “Open original” returns to the source thread. Confirm the newsletter remains in Tideline.
  4. Verify local lifecycle controls in both themes: normal, selected/pressed, hover/focus, loading, error, and disabled. Refresh after a correction and confirm it persists.
  5. Expose the API through a reviewer-controlled public HTTPS endpoint. Configure exact issuer/resource values and an allowed ChatGPT/Codex OAuth callback; loopback HTTP is development-only.
  6. Connect the remote MCP server, approve only read scopes/accounts, call list_agent_events and get_thread, then inspect the source link.
  7. Revoke the connection in Orca and repeat the read. It must fail immediately. Reconnect with one account and confirm another account never appears.

Honest environment boundary: the repository suite proves the full OAuth issuance → MCP read → live revocation path locally.
