Orca provider setup

Connect Microsoft Outlook

This creates a read-first Microsoft Entra OAuth application. Orca requests mailbox reading and identity only; it does not request write or send access.

Microsoft Entra

  1. Register a web application in the Microsoft Entra admin center.
  2. Add http://localhost:3000/v1/auth/outlook/callback as a Web redirect URI.
  3. Add delegated Microsoft Graph permissions: User.Read Mail.Read offline_access.
  4. Create a client secret and copy its value immediately.

Orca environment

OUTLOOK_CLIENT_ID=...
OUTLOOK_CLIENT_SECRET=...
OUTLOOK_TENANT_ID=common
OUTLOOK_REDIRECT_URI=http://localhost:3000/v1/auth/outlook/callback

Use /v1/auth/outlook/login for Outlook-only sign-in or /v1/auth/outlook/connect for an authenticated Orca user.
