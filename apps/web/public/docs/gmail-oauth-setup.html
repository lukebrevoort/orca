Orca setup guide

Gmail OAuth for local development

Use these values when creating the Google Cloud OAuth client that backs Orca's Gmail read-only connection flow.

Google Cloud Console

  1. Create or select a Google Cloud project.
  2. Configure the OAuth consent screen and add yourself as a test user while the app is unpublished.
  3. Create an OAuth client ID with application type Web application.
  4. Add http://localhost:5173 to Authorized JavaScript origins.
  5. Add http://localhost:3000/v1/auth/gmail/callback to Authorized redirect URIs.
  6. Enable the Gmail API for the project.

Local environment

Copy the client values into .env and restart the API.

GMAIL_CLIENT_ID=your-google-client-id
GMAIL_CLIENT_SECRET=your-google-client-secret
GMAIL_REDIRECT_URI=http://localhost:3000/v1/auth/gmail/callback
GMAIL_OAUTH_SCOPES=https://www.googleapis.com/auth/gmail.readonly https://www.googleapis.com/auth/userinfo.email
WEB_ORIGIN=http://localhost:5173

Manual test

  1. Run bun run dev:api and bun run dev:web.
  2. Open http://localhost:5173/login.
  3. Select Continue with Google.
  4. Approve the read-only Gmail grant.
  5. Confirm Orca returns to /settings/integrations/gmail?status=success.
