BRE-268 · Manual validation card

Important machine mail, surfaced without pretending it is human.

Orca adds a short, explainable, local signal to the default timeline. The source remains ordinary provider mail in Tideline and All mail; every user action changes only Orca’s projection.

deterministic M6 rulesaccount scopedno provider writesno OpenAI dependencyreversible controls

Core flow

1 · NoticeOpen /dev/inbox. “Worth a look” is visually separate from human rows and Tideline.
2 · UnderstandRead what happened, why Orca surfaced it, category, rule/version, sender, subject, account, and lifecycle.
3 · SourceChoose “Open original.” Confirm the exact account/thread reader opens.
4 · ReturnChoose Inbox Back. Confirm scroll position and focus return to that event’s source button.
5 · RecoverDismiss or mark “Not useful,” open “Review quieted,” then Restore. Refresh and confirm the state persists.

State gallery

  1. /dev/inbox?agentUi=loading — bounded skeleton with an accessible loading label.
  2. /dev/inbox?agentUi=error — list failure and “Try signals again.”
  3. /dev/inbox?agentUi=action-error — per-event save failure; source mail remains available.
  4. /dev/inbox?agentUi=disabled — readable disabled labels and “Saving locally…” status.

Theme and input pass

  1. Validate the default card and every action in light mode.
  2. Toggle dark mode and repeat default, hover, focus-visible, pressed “Review quieted,” open mute menu, loading, error, and disabled states.
  3. Confirm labels—not color alone—communicate New, Seen, Dismissed, Snoozed, Muted, Not useful, and Retracted.
  4. Tab through actions; focus rings and all labels must remain readable.

Safety boundary

  • ✓ Lifecycle requests are owner + account scoped.
  • ✓ Revision conflicts are explicit; no last-write-wins overwrite.
  • ✓ “Not useful” never changes Human Signal.
  • ✓ No send, draft, archive, delete, relabel, or provider navigation route is called.
  • ✓ Errors contain bounded local-projection language, not mail content.

Semantic regression pass

  • Search for newsletter/source subject: normal mail search behavior remains unchanged.
  • Switch Human Inbox → Tideline → All mail: classification remains message-scoped.
  • Open a mixed/follow-up thread: only the exact machine source owns the event.
  • Check attention filters, collections, reminders, pins, and reader actions: signals do not alter their counts or membership.
