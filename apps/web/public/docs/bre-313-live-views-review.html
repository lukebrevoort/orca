Unlimited live Views,
not another folder system.

Views persist only a typed query definition. Every result is evaluated from the current cross-Account Thread, Lane, Facet, Context, Workflow State, Human Signal evidence, sender, date, and Thread state.

The slice at a glance

IdentityComplete authoritative lifecycle

Create, definition edit, canonical reorder, and remove require both Workspace and resource revisions, a first-party Capability, and an idempotency identity.

MembershipNever persisted

There is intentionally no View membership table. The same Thread can match any number of Views while its Lane row remains singular.

ExecutionTwo bounded phases, one snapshot

An expression-index scan selects at most limit + 1 ordered Thread IDs. In the same read transaction, at most 100 IDs receive the full projection and their first-query order is restored in application code.

AuthorityOne Organization boundary

View writes reuse the existing Organization authority, Workspace change-set, action-evidence, and replay machinery. Authorization is rechecked inside the same SQLite transaction as the mutation.

Live evaluation path

Current filters

The typed View definition is evaluated live across Thread and Organization state.

Ordered IDs

threads_view_order_idx drives keyset order and stops after limit + 1 without a temporary B-tree.
