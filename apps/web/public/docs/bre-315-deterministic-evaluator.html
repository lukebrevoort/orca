05

Manual reviewer path

Use the real Organization screen. The checks below cover content, interaction, theme safety, and immutable storage.

Complete Trace

  1. Open /?destination=organization with a signed-in Workspace that has a recorded evaluation.
  2. Confirm the ready status names the exact Trace and Thread and matches the visible winner/loser totals.
  3. Select Open complete Trace.
  4. Confirm Evaluation/Event/Rule Set/Workspace snapshot IDs, Actor, reason, and logical time are visible.
  5. Confirm every considered revision includes order, Event/Predicate/authorization results; every Predicate includes observed values including missing data.
  6. Confirm each candidate identifies winner/loser, typed action, source/revision/order, exact Actor, authorization and missing Capabilities, reason, and winner link.
  7. Confirm the full Capability Snapshot identity, revision, scope, operations, resource families, and action families is present.

Theme and controls

  1. Check Light and Orca Black.
  2. Inspect default, hover, keyboard focus, selected Glass Box tab, disabled Audit, and open Trace states.
  3. Verify ready, empty, and error status wording is readable, truthful, and does not retain a prior Trace or compile-only claim.
  4. Every state must retain a readable label, visible border, and ink foreground.
  5. Confirm attention, retention, and provider deletion entries say Proposal.
