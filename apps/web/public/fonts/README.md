# Local correspondence fonts

Unmodified variable TrueType fonts, served from this app's origin. No Google
Fonts stylesheet, CDN font, analytics or third-party font request is required.
`font-display: swap` and platform sans/serif fallbacks keep text available if a
font asset fails. Browser font readiness and normal screenshots need no bypass.

Total font payload: 563064 bytes before HTTP compression/cache. These preserve
the existing Sora UI / Newsreader reading identity and include the upstream
character coverage rather than a Latin-only subset. No new font family/design
is introduced. Sora supports weights 100–800; Newsreader 200–800 plus its optical
size axis. Browser synthesis/fallback supplies glyphs/styles not in these faces.
